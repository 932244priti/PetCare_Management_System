# 🐾 PetCare Management System

## 📌 Project Overview

The **PetCare Management System** is a console-based application developed using Java in Eclipse IDE. It is designed to manage pet owners, pets, veterinarians, appointments, vaccinations, and treatments through a menu-driven interface.

The system provides an organized way to maintain pet care records and demonstrates the practical implementation of Object-Oriented Programming (OOP) concepts in Java. It also supports loading previously saved data when the application starts.

## ✨ Features

- **Add Pet Owner:** Register new pet owners.
- **View Pet Owners:** Display registered pet owner records.
- **Add Pet:** Add pet details to the system.
- **View Pets:** Display available pet records.
- **Add Veterinarian:** Register veterinarian information.
- **View Veterinarians:** Display registered veterinarians.
- **Book Appointment:** Schedule appointments for pet care.
- **View Appointments:** Display booked appointments.
- **Add Vaccination:** Maintain vaccination records.
- **View Vaccinations:** Display vaccination details.
- **Add Treatment:** Record pet treatments.
- **View Treatments:** Display treatment information.
- **Data Loading:** Load previously saved data when the application starts.
- **Menu-Driven Interface:** Navigate through the system using console options.

## ⚙️ Application Workflow

1. Start the application.
2. Load previously saved data.
3. Select an operation from the main menu.
4. Add or view pet owners, pets, and veterinarians.
5. Book and view appointments.
6. Add and view vaccinations and treatments.
7. Exit the application using the Exit option.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project using **File → Import → Existing Projects into Workspace**.
4. Select the project folder.
5. Locate the main Java class containing the `main()` method.
6. Right-click the class and select **Run As → Java Application**.
7. Use the console menu to interact with the application.
